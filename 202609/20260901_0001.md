#### 4.3.1 컨테이너에 웹 애플리케이션 등록

```aiignore
웹 애플리케이션을 톰켓 컨테이너에 등록하는 방법 2가지 

1) %CATALINA_HOME/webApps 디렉토리에 애플리케이션을 저장 

2) server.xml 에 직접 웹 애플리케이션을 등록 
```

#### windows 에서 startup.bat 으로 tomcat 실행시 로그 메세지의 한글이 깨지는 경우 
```aiignore
1) chcp 로 현재 cmd 창의 charset 을 확인한다.
C:\WORKS\WORKS_TOMCAT\TOMCAT\apache-tomcat-9.0.121\bin>chcp
활성 코드 페이지: 949

C:\WORKS\WORKS_TOMCAT\TOMCAT\apache-tomcat-9.0.121\bin>

윈도우 CP949 에서 TOMCAT 은 UTF-8 인 경우 메세지가 깨진다.

[대책]
1) cmd 창에서 chcp 65001 실행 
- 창이 새로 열린다.
Active code page: 65001

C:\WORKS\WORKS_TOMCAT\TOMCAT\apache-tomcat-9.0.121\bin>chcp
Active code page: 65001

C:\WORKS\WORKS_TOMCAT\TOMCAT\apache-tomcat-9.0.121\bin>


2) startup.bat 실행
새 창이 열리면서 한글이 깨지면 3 진행

3) startup.bat 실행창에서 catalina.bat run 실행

"catalina.bat run"

현재창에서 한글이 안깨지는지 확인


[권장대책]
startup-utf8.bat 를 생성한다.

@echo off
start "Tomcat" cmd /k "chcp 65001 > nul && catalina.bat run"


startup-utf8.bat 를 $TOMCAT_HOME/bin 에 넣고 실행한다.
그럼 startup.bat, catalina.bat 수정이 불필요하다.
```
